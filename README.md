# OCGW — OGDUNDERCULTURE WORLD

A production-ready editorial, commerce, and community prototype for an underground hip-hop and streetwear publication.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons
- Local optimized WebP artwork

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

The project includes responsive editorial, shop, product, forum, thread, and manifesto routes plus mock API handlers for feed and shop data.
